# 講義 Markdown 標記

`tools/md2html.mjs` 依這份約定把 `content/handout/<slug>.md` 轉成 `handout/<slug>.html`。一般的 Markdown 照常寫；下面是對應到網頁元件的部分。範例：`content/handout/monitor-esp32cam.md`。

## 檔頭

```yaml
---
slug: monitor-esp32cam        # 檔名：handout/monitor-esp32cam.html，要和 md 的檔名相同
type: project                 # tool / hardware / concept / project / advanced / resource
tag: 微專題 02                # 類型標籤上的字；不寫就用類型名稱（工具、硬體……）
version: ESP32-CAM 版         # kicker 後面的字；沒有版本就不寫
title: 簡易 AI 監控系統
lead: 一句話說這份講義做什麼。
scope: 專題才要：學習用雛形的說明，顯示在頁首的框
meta:                         # 頁首的「適用」「零件」這類資訊，可以不寫
  適用: AI Thinker ESP32-CAM
badge: 框架稿・範例程式碼待補   # 未完成時寫；拿掉後選單卡片的「撰寫中」會一起拿掉
updated: 2026-10              # 選單卡片的「更新於」
switch: [改看 Uno 版 →](alarm-uno.html)    # 有其他版本時，頁首的切換連結
next: [ESP32-CAM](esp32-cam.html)         # 頁尾的下一篇
here: 簡易 AI 監控系統・ESP32-CAM 版       # 頂端導覽列的名稱；預設是 title・version
---
```

## 內文

| 寫法 | 網頁上 |
|---|---|
| `## 標題` | 一節，自動編號 01、02……，同時產生目錄。`{#id}` 可以指定錨點，預設 s1、s2…… |
| `### 標題`、`### 標題 {#id}` | 小標 |
| `#### 標題` | 在步驟裡是步驟小標（程式、完成標準……）；在折疊區裡是 h4 |
| 段落 | 換行會接起來，中文之間不加空格 |
| `**粗體**` | 粗體 |
| `` `程式碼` `` | 內文裡是程式碼字體；**表格裡**變成等寬字（腳位、數值用這個） |
| `- 清單`、`1. 清單` | 內文清單；縮排兩格可以有第二層 |
| 表格 | 手機上疊成卡片的表格；第一欄是列標題；表頭第一格可以空著 |
| `[文字](setup.html#s2)` | 站內連結，寫 .html 檔名 |
| `[文字](https://…)` | 外部連結：另開分頁，自動加 ↗ |
| `> [!NOTE]` 開頭的引言 | 灰色小字補充；空一行分成好幾段 |
| `> 「……」` | 一節開頭的引導問題 |
| ` ```sh ` | 終端機指令，有複製鈕 |
| ` ```prompt ` | 給 AI 的提示詞，有複製鈕 |
| ` ```py ` 等其他語言 | 一般程式區塊（短的片段才用；完整程式用 @code） |
| `@code python/monitor.py` | 從 `handout/code/` 讀程式檔，顯示成有行數的程式區塊。`name=config.json` 改顯示名稱 |
| `![替代文字](../assets/handout/img/x.webp)`，下一行 `*圖說*` | 圖片和圖說；尺寸和圖片來源從 `credits.json` 自動帶入 |
| 以 `<標籤` 開頭的段落 | 原樣放進網頁（需要特殊排版時的出口，少用） |

自動處理的事：

- 每一節的第一個大元件（表格、圖、系統圖、狀態圖、四問表、步驟索引）加上 `lead-in` 間距；出現 `###` 之後就不加。
- 產品名稱自動用 `&nbsp;` 連起來：AI Thinker ESP32-CAM、XIAO ESP32-S3 Sense、Teachable Machine、Raspberry Pi、Arduino IDE、Arduino Uno、VS Code。新的名稱加到 md2html.mjs 的 `JOIN`。
- 不在不該斷的地方斷行（`tools/lib/nobreak.mjs`）：有連字號的名稱（ESP32-CAM、Wi-Fi、micro-USB）、數字和單位（5 MB、240 MHz）、「微專題 02」。
- 行內程式碼超過 30 個字會警告：手機上撐出橫向捲動，長指令改用 ` ```sh ` 區塊。
- 用到 `credits.json` 裡的圖片，頁尾自動列出圖片來源。

## 區塊

`:::名稱` 開頭、`:::` 結尾。區塊裡還有區塊時，外層多一個冒號（`::::step` … `::::`）。

| 寫法 | 網頁上 |
|---|---|
| `:::fold 標題` | 可展開的折疊區。標題寫「常見問題」就是常見問題；開頭寫「教學 」或「AI 」會變成標籤 |
| `:::qa` | 四問表。內容是清單，每項 `- **你要準備**：…`；項目下可以縮排一層清單。「常見陷阱」自動標成橘色 |
| `:::fails 小標` | 失效清單，整節連續編號。每項 `- **情況**：結果` |
| `::::step 步驟 1｜標題 {#step1}` | 一個步驟。開頭的 `**標籤**：Python、2.4 GHz Wi-Fi`（第一個是種類）和 `**目標**：…` 會變成標籤列和目標；同一節的步驟自動產生索引。`{#id}` 預設 step1、step2…… |
| `:::terms` | 「這一步的新名詞」。每項 `- **名詞**：解釋` |
| `:::system` | 系統圖。每行一格 `裝置：ESP32-CAM｜小字`，標籤加粗 `**閘道**：…` 是核心那一格；箭頭行 `→ Wi-Fi`（字要短）；`+ 一句話` 是圖下方的補充 |
| `:::states` | 狀態流程圖。每行一個狀態 `沒人｜輸出`，加粗 `**警報**｜…` 是警報狀態；箭頭行 `→ 條件`；`↺ 說明` 是圖下方的虛線框 |
| `:::diagram 標題 {#id}` | 要 Claude 畫的圖。內容寫清楚畫面裡有什麼、要強調什麼。圖畫好前，預覽顯示成待畫的框，上網頁會被擋下 |
| `:::todo 標題` | 虛線框的「待補」清單。每項 `` - `檔名`：說明 `` |

## 只在 md 裡

| 寫法 | 用途 |
|---|---|
| `<!-- 給 Claude：… -->` | 給 Claude 的指示，不會上網頁；還在的話上網頁會被擋下 |
| `<!-- 其他註解 -->` | 不會上網頁 |
| `[待查]` | 要查證的地方。預覽時標黃，上網頁會被擋下 |

## 圖

`:::diagram 標題 {#id}` 的圖存成 `assets/handout/fig/<slug>/<id>.html`，內容是完整的圖的 HTML（外層的 `<figure>` 和圖說也寫在裡面），轉換時原樣嵌入。

- SVG 用 `handout.css` 裡現成的 class：`.dg`（線條、`.face`、`.shade`、`.tint`、`.hl`、文字）、`.scenes`／`.scene`（兩欄情境圖）、`.tasks`／`.tk`（三欄對照）。顏色只用 token。
- 圖片寬度跟著欄寬縮放；手機 390 寬時，圖裡的字縮完要還看得清楚（viewBox 寬 480 時，字至少 14）。
- 每張 SVG 要有 `role="img"` 和描述畫面的 `aria-label`。
