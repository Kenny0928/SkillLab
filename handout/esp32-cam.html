01

板子上有什麼

正面

  • 相機：OV2640，用排線接在板子的插座上。
  • 記憶卡槽：在相機下面，放 microSD 卡。
  • 閃光燈：右下角的白色大 LED，接 GPIO 4，很亮。
  • 排針：左右各 8 支，腳位名稱印在旁邊。

背面

  • ESP32-S 模組：金屬殼裡是經典款 ESP32 晶片。
  • PSRAM：4 MB 的額外記憶體，存照片用。
  • 紅色小 LED：接 GPIO 33，程式輸出 LOW 才會亮。
  • RST 鍵：重新開機。
  • 天線：板上有印刷天線，另有外接天線的小插座。

燒錄底板 ESP32-CAM-MB

ESP32-CAM 板上沒有 USB 接口，要插在燒錄底板上才能接電腦。底板負責三件事：

  • USB 轉序列：板上的 USB 晶片多半是 CH340，電腦找不到時先裝驅動程式，見環境安裝講義。
  • 供電：把 USB 的 5V 供給 ESP32-CAM。
  • 按鈕：IO0 鍵和 RST 鍵，燒錄失敗時用來手動進入燒錄模式。

插上底板時，對照兩塊板子上印的腳位名稱（5V、GND、IO12……）插，不要插反。燒好程式以後，ESP32-CAM 可以留在底板上，用 USB 充電器供電。

02

規格要看什麼

規格ESP32-CAM什麼時候要在乎
處理器經典款 ESP32，雙核心 240 MHz，沒有 AI 加速想在板子上做 AI 辨識時：跑不動物件偵測，只能做顏色篩選、畫面變化這類簡單的運算。
記憶體520 KB，加上 4 MB PSRAM拍高解析度照片時。PSRAM 要選對開發板才會啟用。
程式空間4 MB 快閃記憶體，程式最多約 3 MB程式加上網頁、Wi-Fi、相機函式庫時，已經用掉三分之一。
相機OV2640，200 萬像素，最大 1600×1200，相機直接輸出 JPEG要拍清楚的照片時。小鏡頭在暗處畫質很差，也沒有紅外線夜視。
記憶卡microSD要存照片時。用 32 GB 以下、格式化成 FAT32 的卡最穩。
無線Wi-Fi 2.4 GHz、藍牙現場只有 5 GHz，或要網頁登入的 Wi-Fi，連不上。
供電5V，從底板的 USB 供電Wi-Fi 傳送和閃光燈會讓電流突然變大，電源不穩就重新開機。
腳位排針 16 支，大多被相機和記憶卡佔用要接感測器時，能用的只剩一兩支，見第 04 節。

有些賣家的 ESP32-CAM 換成 OV3660 或 OV5640 相機，程式要做的調整比較多。買的時候看清楚相機型號。

03

燒錄與第一次執行

先照環境安裝講義裝好 Arduino IDE 和 ESP32 開發板套件。Arduino IDE 的「工具」選單這樣設定：

選項選什麼
開發板esp32 → AI Thinker ESP32-CAM
Partition SchemeHuge APP (3MB No OTA/1MB SPIFFS)，選了開發板就是這個
連接埠底板插上電腦後多出來的那一個
序列埠監控視窗115200 baud
  1. 把 ESP32-CAM 插在底板上，用 USB 傳輸線接電腦。
  2. 選好開發板和連接埠，按「上傳」。
  3. 一直停在 Connecting......：按住底板的 IO0 鍵，按一下 RST 鍵再放開，最後放開 IO0，再按一次上傳。
  4. 上傳完成後，按一下 RST 鍵，程式才會開始執行。
  5. 打開序列埠監控視窗，選 115200。沒有看到文字，就再按一次 RST 鍵。

選了 AI Thinker ESP32-CAM，打開序列埠監控視窗不會讓板子重新開機，所以開機時印的文字要按 RST 才看得到。

04

腳位

相機用掉了 ESP32 大部分的腳，排針上的 16 支也大多有別的用途：

排針用途能接零件嗎
左排（照第 01 節照片的方向）
5V・GND電源輸入不用底板時，從這裡接 5V 供電
IO12記憶卡（4-bit 模式）；開機模式腳可以，但開機那一刻不能是高電位，否則開不了機
IO13記憶卡（4-bit 模式）最適合：用 1-bit 模式或不插記憶卡時就空出來
IO15・IO14・IO2記憶卡（兩種模式都用）；IO2、IO15 是開機模式腳不插記憶卡時才可以
IO4閃光燈；記憶卡（4-bit 模式）接了零件，閃光燈會跟著亮
右排
3V3・GND3.3V 輸出給 3.3V 的感測器供電
IO16PSRAM不行
IO0相機時脈；燒錄模式腳不行
VCC電源輸出，多半是 3.3V不要從這裡接電源進去
U0R・U0TGPIO 3、1，燒錄和序列埠監控視窗用不要接，否則不能燒錄

要接人體紅外線感測器或按鈕，先用 IO13，記憶卡用 1-bit 模式（範例 4 的寫法）。要接很多零件，就換一塊 ESP32 開發板，或讓兩塊板子用序列埠互傳。

05

適合用在哪裡

ESP32-CAM 擅長「拍下來、傳出去」：便宜、小、自己連 Wi-Fi。複雜的判斷交給電腦或雲端。

場合例子做法
遠端看畫面看寵物、看 3D 列印進度、小車的第一人稱鏡頭範例 2、3：同一個網路的手機或電腦用瀏覽器看
定時拍照紀錄植物生長、天空變化、作品製作過程的縮時攝影範例 4：照片存在記憶卡，不用網路
有動靜才記錄信箱有沒有信、抽屜有沒有被打開、走廊有沒有人經過範例 5：畫面變化超過門檻才拍；或在 IO13 接人體紅外線感測器
交給電腦做 AI 辨識數人數、認出有沒有人、判斷姿勢範例 3 送出畫面，電腦用影像辨識講義的程式辨識（微專題 02）

不適合

  • 板子上直接跑 AI 物件偵測：換 ESP32-S3、AMB82-mini 這類有 AI 加速的板子，或交給電腦。
  • 錄影存檔：沒有影片壓縮，只能一張一張存 JPEG，記憶卡也寫得慢。
  • 暗處、夜間：沒有紅外線，閃光燈只照得到眼前一點。
  • 用電池撐很久：開著 Wi-Fi 串流時一直耗電。
  • 接很多感測器：能用的腳只有一兩支。
  • 戶外長期使用：要另外處理防水、日曬和散熱。

範例 1

檢查板子

Arduino不用接線

目標：確認能燒錄，印出晶片和記憶體的資訊，讓紅色 LED 和閃光燈閃爍。

程式

board_check.ino41 行
// 範例 1：檢查板子（PSRAM、快閃記憶體、LED）
// 開發板選「AI Thinker ESP32-CAM」，序列埠監控視窗的速率選 115200
// 紅色 LED 在板子背面，接 GPIO 33，輸出 LOW 才會亮
// 閃光燈是正面的白色大 LED，接 GPIO 4，很亮，不要直視

const int RED_LED = 33;    // 板子背面的紅色小 LED
const int FLASH_LED = 4;   // 正面的閃光燈
const int FLASH_MAX = 30;  // 閃光燈亮度上限（0–255），太亮會刺眼又發燙

void setup() {
  Serial.begin(115200);
  delay(500);
  pinMode(RED_LED, OUTPUT);
  ledcAttach(FLASH_LED, 5000, 8);  // PWM：5 kHz、8 位元（0–255）

  Serial.println();
  Serial.println("===== ESP32-CAM 檢查 =====");
  Serial.printf("晶片：%s，%d 核心，%d MHz\n", ESP.getChipModel(), ESP.getChipCores(), ESP.getCpuFreqMHz());
  Serial.printf("快閃記憶體：%u MB\n", ESP.getFlashChipSize() / (1024 * 1024));
  if (psramFound()) {
    Serial.printf("PSRAM：%u KB（可以拍高解析度照片）\n", ESP.getPsramSize() / 1024);
  } else {
    Serial.println("PSRAM：找不到。開發板沒選 AI Thinker ESP32-CAM，或板子沒有 PSRAM");
  }
}

void loop() {
  // 紅色 LED 亮，閃光燈慢慢變亮
  digitalWrite(RED_LED, LOW);
  for (int d = 0; d <= FLASH_MAX; d++) {
    ledcWrite(FLASH_LED, d);
    delay(20);
  }
  // 紅色 LED 滅，閃光燈慢慢變暗
  digitalWrite(RED_LED, HIGH);
  for (int d = FLASH_MAX; d >= 0; d--) {
    ledcWrite(FLASH_LED, d);
    delay(20);
  }
  delay(400);
}

完成標準

按 RST 後，序列埠監控視窗印出晶片 ESP32、快閃記憶體 4 MB、PSRAM 約 4096 KB；背面的紅色 LED 和正面的閃光燈一起慢慢閃。

常見問題
  • PSRAM 找不到：開發板沒選 AI Thinker ESP32-CAM；選對了還是找不到，可能是仿冒板。
  • 編譯錯誤 ledcAttach 不存在：ESP32 開發板套件是 2.x 版，請升級到 3.3 版。

這一步的新名詞

PSRAM
接在 ESP32 外面的記憶體，比較慢但容量大。一張高解析度照片放不進 ESP32 內建的 520 KB，要放在這裡。
PWM
快速開關腳位，用「開著的時間比例」控制亮度。ledcWrite 的數字 0–255 就是這個比例。

範例 2

官方範例：網頁看畫面、調設定

Arduino瀏覽器2.4 GHz Wi-Fi

目標：用瀏覽器看即時畫面，試試解析度、畫質、亮度這些設定。

步驟

  1. 開發板先選好 AI Thinker ESP32-CAM，再打開「檔案 → 範例 → ESP32 → Camera → CameraWebServer」，另存到課程資料夾。
  2. 切到 board_config.h 分頁：在 #define CAMERA_MODEL_ESP_EYE 前面加上 //，再把 //#define CAMERA_MODEL_AI_THINKER 前面的 // 刪掉。
  3. 回到 CameraWebServer.ino，把 ssid 和 password 的星號換成你的 Wi-Fi 名稱和密碼。
  4. 上傳，按 RST。序列埠監控視窗最後會印出 Camera Ready! 和板子的網址，例如 http://192.168.1.23。
  5. 用同一個 Wi-Fi 的電腦或手機打開這個網址，按「Start Stream」。

完成標準

看到即時畫面。左邊的 Resolution 從 QVGA 調到 UXGA，畫面變清楚、也變慢；LED Intensity 可以調閃光燈亮度。

常見問題
  • Camera init failed with error 0x20001（或 0x105）：找不到相機。board_config.h 沒改成 AI_THINKER，或相機排線沒插好。
  • 一直印 WiFi connecting……：名稱或密碼打錯，或 Wi-Fi 是 5 GHz。
  • 網址打不開：電腦和板子不在同一個網路。學校、公共 Wi-Fi 常會擋同一個網路裡的裝置互連，改用手機熱點。

串流與拍照網址

目標：只留三個網址：首頁、拍一張、連續串流。程式比官方範例短很多，微專題 02 的 Python 從 /capture 拿畫面。

程式

燒錄前先改 WIFI_SSID、WIFI_PASS。

cam_server.ino194 行
// 範例 3：串流與拍照網址（微專題 02 的 Python 從這裡拿畫面）
// 開發板選「AI Thinker ESP32-CAM」，序列埠監控視窗的速率選 115200
// 燒錄前先改 WIFI_SSID、WIFI_PASS；只能連 2.4 GHz 的 Wi-Fi
// 開機後序列埠會印出板子的 IP，例如 192.168.1.23：
//   http://192.168.1.23/           瀏覽器看即時畫面
//   http://192.168.1.23/capture    拍一張 JPEG（Python 用這個）
//   http://192.168.1.23:81/stream  連續畫面（同時只能一個人看）
// 這些網址沒有密碼，連到同一個 Wi-Fi 的人都打得開

#include "esp_camera.h"
#include "esp_http_server.h"
#include <WiFi.h>

const char *WIFI_SSID = "你的 Wi-Fi 名稱";
const char *WIFI_PASS = "你的 Wi-Fi 密碼";

const framesize_t FRAME_SIZE = FRAMESIZE_VGA;  // 640×480；要更順可以改 FRAMESIZE_QVGA（320×240）
const int JPEG_QUALITY = 12;                   // 10–63，數字越小畫質越好、檔案越大
const int RED_LED = 33;                        // 背面紅色 LED，LOW 亮：亮著代表沒連上 Wi-Fi
const int FLASH_LED = 4;                       // 閃光燈，這個範例不用，保持關閉

// AI Thinker ESP32-CAM 的相機腳位（和官方範例 camera_pins.h 的 CAMERA_MODEL_AI_THINKER 相同）
#define PWDN_GPIO_NUM  32
#define RESET_GPIO_NUM -1
#define XCLK_GPIO_NUM  0
#define SIOD_GPIO_NUM  26
#define SIOC_GPIO_NUM  27
#define Y9_GPIO_NUM    35
#define Y8_GPIO_NUM    34
#define Y7_GPIO_NUM    39
#define Y6_GPIO_NUM    36
#define Y5_GPIO_NUM    21
#define Y4_GPIO_NUM    19
#define Y3_GPIO_NUM    18
#define Y2_GPIO_NUM    5
#define VSYNC_GPIO_NUM 25
#define HREF_GPIO_NUM  23
#define PCLK_GPIO_NUM  22

#define BOUNDARY "frame"

// 首頁：一張圖，來源是 81 埠的串流
const char INDEX_HTML[] = R"html(<!doctype html>
<html lang="zh-Hant"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1"><title>ESP32-CAM</title>
<style>body{margin:0;background:#111;color:#eee;font-family:sans-serif;text-align:center}img{max-width:100%}a{color:#f9a}</style>
</head><body><img id="v" alt="即時畫面"><p><a href="/capture">拍一張</a></p>
<script>document.getElementById("v").src = "http://" + location.hostname + ":81/stream";</script>
</body></html>)html";

httpd_handle_t webServer = NULL;     // 80 埠：首頁、拍照
httpd_handle_t streamServer = NULL;  // 81 埠：串流

bool initCamera() {
  camera_config_t c = {};
  c.ledc_channel = LEDC_CHANNEL_0;
  c.ledc_timer = LEDC_TIMER_0;
  c.pin_d0 = Y2_GPIO_NUM;
  c.pin_d1 = Y3_GPIO_NUM;
  c.pin_d2 = Y4_GPIO_NUM;
  c.pin_d3 = Y5_GPIO_NUM;
  c.pin_d4 = Y6_GPIO_NUM;
  c.pin_d5 = Y7_GPIO_NUM;
  c.pin_d6 = Y8_GPIO_NUM;
  c.pin_d7 = Y9_GPIO_NUM;
  c.pin_xclk = XCLK_GPIO_NUM;
  c.pin_pclk = PCLK_GPIO_NUM;
  c.pin_vsync = VSYNC_GPIO_NUM;
  c.pin_href = HREF_GPIO_NUM;
  c.pin_sccb_sda = SIOD_GPIO_NUM;
  c.pin_sccb_scl = SIOC_GPIO_NUM;
  c.pin_pwdn = PWDN_GPIO_NUM;
  c.pin_reset = RESET_GPIO_NUM;
  c.xclk_freq_hz = 20000000;
  c.pixel_format = PIXFORMAT_JPEG;     // 相機直接輸出 JPEG
  c.frame_size = FRAME_SIZE;
  c.jpeg_quality = JPEG_QUALITY;
  c.fb_count = 2;                      // 兩個畫面緩衝區，放在 PSRAM
  c.fb_location = CAMERA_FB_IN_PSRAM;
  c.grab_mode = CAMERA_GRAB_LATEST;    // 永遠拿最新的畫面
  esp_err_t err = esp_camera_init(&c);
  if (err != ESP_OK) {
    Serial.printf("相機啟動失敗：0x%x（排線沒插好，或開發板選錯）\n", err);
    return false;
  }
  return true;
}

// http://IP/
esp_err_t indexHandler(httpd_req_t *req) {
  httpd_resp_set_type(req, "text/html; charset=utf-8");
  return httpd_resp_send(req, INDEX_HTML, HTTPD_RESP_USE_STRLEN);
}

// http://IP/capture：回傳一張 JPEG
esp_err_t captureHandler(httpd_req_t *req) {
  camera_fb_t *fb = esp_camera_fb_get();
  if (!fb) {
    httpd_resp_send_500(req);
    return ESP_FAIL;
  }
  httpd_resp_set_type(req, "image/jpeg");
  httpd_resp_set_hdr(req, "Cache-Control", "no-store");
  httpd_resp_set_hdr(req, "Access-Control-Allow-Origin", "*");
  esp_err_t res = httpd_resp_send(req, (const char *)fb->buf, fb->len);
  esp_camera_fb_return(fb);
  return res;
}

// http://IP:81/stream：一張接一張送 JPEG，直到對方關掉
esp_err_t streamHandler(httpd_req_t *req) {
  httpd_resp_set_type(req, "multipart/x-mixed-replace;boundary=" BOUNDARY);
  httpd_resp_set_hdr(req, "Access-Control-Allow-Origin", "*");
  char head[80];
  while (true) {
    camera_fb_t *fb = esp_camera_fb_get();
    if (!fb) return ESP_FAIL;
    int n = snprintf(head, sizeof(head),
                     "\r\n--" BOUNDARY "\r\nContent-Type: image/jpeg\r\nContent-Length: %u\r\n\r\n", fb->len);
    esp_err_t res = httpd_resp_send_chunk(req, head, n);
    if (res == ESP_OK) res = httpd_resp_send_chunk(req, (const char *)fb->buf, fb->len);
    esp_camera_fb_return(fb);
    if (res != ESP_OK) return res;  // 瀏覽器或 Python 關掉了
  }
}

void startServers() {
  httpd_config_t config = HTTPD_DEFAULT_CONFIG();
  httpd_uri_t indexUri = {.uri = "/", .method = HTTP_GET, .handler = indexHandler, .user_ctx = NULL};
  httpd_uri_t captureUri = {.uri = "/capture", .method = HTTP_GET, .handler = captureHandler, .user_ctx = NULL};
  httpd_uri_t streamUri = {.uri = "/stream", .method = HTTP_GET, .handler = streamHandler, .user_ctx = NULL};

  if (httpd_start(&webServer, &config) == ESP_OK) {
    httpd_register_uri_handler(webServer, &indexUri);
    httpd_register_uri_handler(webServer, &captureUri);
  }
  // 串流會一直佔著伺服器，所以另外開一個在 81 埠
  config.server_port += 1;
  config.ctrl_port += 1;
  if (httpd_start(&streamServer, &config) == ESP_OK) {
    httpd_register_uri_handler(streamServer, &streamUri);
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(RED_LED, OUTPUT);
  digitalWrite(RED_LED, LOW);
  pinMode(FLASH_LED, OUTPUT);
  digitalWrite(FLASH_LED, LOW);

  if (!initCamera()) {
    while (true) delay(1000);  // 相機壞了就停在這裡，紅燈一直亮
  }

  WiFi.mode(WIFI_STA);
  WiFi.setSleep(false);  // 關掉 Wi-Fi 省電模式，畫面延遲比較小
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  Serial.print("連線 Wi-Fi");
  unsigned long start = millis();
  while (WiFi.status() != WL_CONNECTED) {
    if (millis() - start > 20000) {
      Serial.println("\n連不上 Wi-Fi：檢查名稱、密碼，以及是不是 2.4 GHz。5 秒後重新開機");
      delay(5000);
      ESP.restart();
    }
    delay(500);
    Serial.print(".");
  }
  digitalWrite(RED_LED, HIGH);

  startServers();
  String ip = WiFi.localIP().toString();
  Serial.println();
  Serial.println("即時畫面：http://" + ip + "/");
  Serial.println("拍一張：  http://" + ip + "/capture");
  Serial.println("串流：    http://" + ip + ":81/stream");
}

void loop() {
  // 網頁伺服器在背景執行，這裡只顯示 Wi-Fi 狀態
  static bool wasConnected = true;
  bool connected = WiFi.status() == WL_CONNECTED;
  if (connected != wasConnected) {
    if (connected) {
      Serial.println("Wi-Fi 重新連上了，IP：" + WiFi.localIP().toString());  // IP 可能和之前不同
    } else {
      Serial.println("Wi-Fi 斷線，自動重連中");
    }
    digitalWrite(RED_LED, connected ? HIGH : LOW);
    wasConnected = connected;
  }
  delay(1000);
}

Wi-Fi 密碼寫在程式裡，截圖、貼給 AI 或上傳 GitHub 之前先刪掉。

完成標準

  • 按 RST 後序列埠印出三個網址，背面紅燈熄滅（亮著代表還沒連上 Wi-Fi）。
  • 瀏覽器打開第一個網址，看到即時畫面；打開 /capture 看到一張照片。
  • 在電腦上用影像辨識講義的程式看 ESP32-CAM 的畫面，出現辨識結果。IP 換成序列埠印出的：
終端機
uv run vision_demo.py --source http://192.168.1.23/capture
常見問題
  • 第二個人打不開串流：串流同時只能一個人看，第二個人會一直等。改用 /capture，或先關掉第一個視窗。
  • 畫面延遲好幾秒：改用 FRAMESIZE_QVGA，或讓板子靠近路由器。
  • 重新開機後網址變了：路由器每次可能分配不同的 IP，以序列埠印出的為準。

這一步的新名詞

IP 位址
裝置在網路裡的地址，例如 192.168.1.23。同一個網路裡的裝置用它找到對方。
MJPEG 串流
一張接一張送 JPEG 照片，瀏覽器收到就換掉上一張，看起來就是影片。
埠
同一台裝置上可以同時開好幾個服務，用埠號區分。網址沒寫就是 80；串流用 81。

範例 4

定時拍照存記憶卡

ArduinomicroSD 卡不用網路

目標：每 10 秒拍一張存到記憶卡，可以拿來做縮時攝影。

準備

記憶卡先在電腦上格式化成 FAT32（32 GB 以下）。拔掉 USB 線，插好記憶卡，再接回去。

程式

timelapse_sd.ino141 行
// 範例 4：定時拍照存到記憶卡
// 開發板選「AI Thinker ESP32-CAM」，序列埠監控視窗的速率選 115200
// 記憶卡：32 GB 以下，先在電腦上格式化成 FAT32，斷電後再插進板子
// 每 INTERVAL_S 秒拍一張，存成 /photo_00001.jpg、/photo_00002.jpg……
// 編號記在板子裡，重新開機會接著往下編

#include "esp_camera.h"
#include "SD_MMC.h"
#include <Preferences.h>

const unsigned long INTERVAL_S = 10;            // 幾秒拍一張
const framesize_t FRAME_SIZE = FRAMESIZE_SVGA;  // 800×600；最大 FRAMESIZE_UXGA（1600×1200）
const int JPEG_QUALITY = 10;                    // 10–63，數字越小畫質越好、檔案越大
const int RED_LED = 33;                         // 背面紅色 LED，LOW 亮：存檔時閃一下
const int FLASH_LED = 4;                        // 閃光燈，保持關閉

// AI Thinker ESP32-CAM 的相機腳位（和官方範例 camera_pins.h 的 CAMERA_MODEL_AI_THINKER 相同）
#define PWDN_GPIO_NUM  32
#define RESET_GPIO_NUM -1
#define XCLK_GPIO_NUM  0
#define SIOD_GPIO_NUM  26
#define SIOC_GPIO_NUM  27
#define Y9_GPIO_NUM    35
#define Y8_GPIO_NUM    34
#define Y7_GPIO_NUM    39
#define Y6_GPIO_NUM    36
#define Y5_GPIO_NUM    21
#define Y4_GPIO_NUM    19
#define Y3_GPIO_NUM    18
#define Y2_GPIO_NUM    5
#define VSYNC_GPIO_NUM 25
#define HREF_GPIO_NUM  23
#define PCLK_GPIO_NUM  22

Preferences prefs;
unsigned long photoNo;   // 下一張照片的編號
unsigned long lastShot;  // 上一次拍照的時間

bool initCamera() {
  camera_config_t c = {};
  c.ledc_channel = LEDC_CHANNEL_0;
  c.ledc_timer = LEDC_TIMER_0;
  c.pin_d0 = Y2_GPIO_NUM;
  c.pin_d1 = Y3_GPIO_NUM;
  c.pin_d2 = Y4_GPIO_NUM;
  c.pin_d3 = Y5_GPIO_NUM;
  c.pin_d4 = Y6_GPIO_NUM;
  c.pin_d5 = Y7_GPIO_NUM;
  c.pin_d6 = Y8_GPIO_NUM;
  c.pin_d7 = Y9_GPIO_NUM;
  c.pin_xclk = XCLK_GPIO_NUM;
  c.pin_pclk = PCLK_GPIO_NUM;
  c.pin_vsync = VSYNC_GPIO_NUM;
  c.pin_href = HREF_GPIO_NUM;
  c.pin_sccb_sda = SIOD_GPIO_NUM;
  c.pin_sccb_scl = SIOC_GPIO_NUM;
  c.pin_pwdn = PWDN_GPIO_NUM;
  c.pin_reset = RESET_GPIO_NUM;
  c.xclk_freq_hz = 20000000;
  c.pixel_format = PIXFORMAT_JPEG;
  c.frame_size = FRAME_SIZE;
  c.jpeg_quality = JPEG_QUALITY;
  c.fb_count = 2;
  c.fb_location = CAMERA_FB_IN_PSRAM;
  c.grab_mode = CAMERA_GRAB_LATEST;  // 拿最新的畫面，不會拿到 10 秒前拍好放著的那張
  esp_err_t err = esp_camera_init(&c);
  if (err != ESP_OK) {
    Serial.printf("相機啟動失敗：0x%x（排線沒插好，或開發板選錯）\n", err);
    return false;
  }
  return true;
}

void stopHere(const char *why) {
  Serial.println(why);
  while (true) {  // 紅燈快閃，表示出錯
    digitalWrite(RED_LED, !digitalRead(RED_LED));
    delay(150);
  }
}

void takePhoto() {
  camera_fb_t *fb = esp_camera_fb_get();
  if (!fb) {
    Serial.println("拍照失敗");
    return;
  }
  char path[24];
  snprintf(path, sizeof(path), "/photo_%05lu.jpg", photoNo);
  File file = SD_MMC.open(path, FILE_WRITE);
  if (!file) {
    Serial.printf("開不了檔案 %s：記憶卡滿了或被拔掉\n", path);
    esp_camera_fb_return(fb);
    return;
  }
  digitalWrite(RED_LED, LOW);
  file.write(fb->buf, fb->len);
  file.close();
  digitalWrite(RED_LED, HIGH);
  Serial.printf("存好 %s（%u KB）\n", path, fb->len / 1024);
  esp_camera_fb_return(fb);

  photoNo++;
  prefs.putULong("next", photoNo);  // 記下編號，重新開機不會蓋掉舊照片
}

void setup() {
  Serial.begin(115200);
  pinMode(RED_LED, OUTPUT);
  digitalWrite(RED_LED, HIGH);

  if (!initCamera()) stopHere("停止");

  // 1-bit 模式只用 GPIO 2、14、15；4-bit 模式會用到 GPIO 4，閃光燈會跟著閃
  if (!SD_MMC.begin("/sdcard", true)) {
    stopHere("讀不到記憶卡：確認有插好、是 FAT32、32 GB 以下");
  }
  pinMode(FLASH_LED, OUTPUT);
  digitalWrite(FLASH_LED, LOW);
  Serial.printf("記憶卡 %llu MB\n", SD_MMC.cardSize() / (1024 * 1024));

  prefs.begin("timelapse", false);
  photoNo = prefs.getULong("next", 1);
  Serial.printf("從第 %lu 張開始，每 %lu 秒拍一張\n", photoNo, INTERVAL_S);

  // 相機剛啟動時自動曝光還沒調好，先丟掉幾張
  for (int i = 0; i < 5; i++) {
    camera_fb_t *fb = esp_camera_fb_get();
    if (fb) esp_camera_fb_return(fb);
    delay(200);
  }
  takePhoto();
  lastShot = millis();
}

void loop() {
  if (millis() - lastShot >= INTERVAL_S * 1000UL) {
    lastShot = millis();
    takePhoto();
  }
}

完成標準

序列埠每 10 秒印一次「存好 /photo_00001.jpg（xx KB）」，紅燈同時閃一下。拔掉電源，把記憶卡插到電腦，照片依編號排好；重新插回去開機，編號接著往下。

常見問題
  • 讀不到記憶卡，紅燈快閃：卡沒插到底、不是 FAT32，或容量太大。
  • 照片太暗或偏色：剛開機時自動曝光還在調，程式已經先丟掉 5 張；光線很暗時照片還是會很暗。
  • 想做成影片：把照片依編號串起來。影片剪輯軟體大多能「匯入圖片序列」。

範例 5

畫面變化偵測

Arduino序列繪圖家不用 AI

目標：在板子上比較前後兩張灰階畫面，畫面有動靜就亮紅燈。原理見影像辨識講義的「畫面相減」。

程式

motion_diff.ino125 行
// 範例 5：畫面變化偵測（不用 AI）
// 開發板選「AI Thinker ESP32-CAM」，序列埠監控視窗的速率選 115200
// 每 0.1 秒拍一張 160×120 的灰階畫面，和上一張逐點比較，算出有幾 % 的像素變了
// 超過門檻就亮紅色 LED，序列埠印出「偵測到畫面變化」
// 打開序列繪圖家，可以看到「變化」和「門檻」兩條線

#include "esp_camera.h"

const int PIXEL_DIFF = 25;            // 一個像素的亮度差超過這個值（0–255），才算「變了」
const float TRIGGER_PERCENT = 5.0;    // 變了的像素超過幾 %，才算畫面有動靜
const unsigned long HOLD_MS = 1000;   // 偵測到之後，紅燈至少亮多久
const unsigned long WARMUP_MS = 3000; // 開機後先等自動曝光穩定
const int RED_LED = 33;               // 背面紅色 LED，LOW 亮
const int FLASH_LED = 4;              // 閃光燈，保持關閉

const int W = 160;
const int H = 120;

// AI Thinker ESP32-CAM 的相機腳位（和官方範例 camera_pins.h 的 CAMERA_MODEL_AI_THINKER 相同）
#define PWDN_GPIO_NUM  32
#define RESET_GPIO_NUM -1
#define XCLK_GPIO_NUM  0
#define SIOD_GPIO_NUM  26
#define SIOC_GPIO_NUM  27
#define Y9_GPIO_NUM    35
#define Y8_GPIO_NUM    34
#define Y7_GPIO_NUM    39
#define Y6_GPIO_NUM    36
#define Y5_GPIO_NUM    21
#define Y4_GPIO_NUM    19
#define Y3_GPIO_NUM    18
#define Y2_GPIO_NUM    5
#define VSYNC_GPIO_NUM 25
#define HREF_GPIO_NUM  23
#define PCLK_GPIO_NUM  22

uint8_t *prevFrame;          // 上一張畫面
bool hasPrev = false;
bool moving = false;         // 現在是不是「有動靜」
unsigned long lastMotion = 0;

bool initCamera() {
  camera_config_t c = {};
  c.ledc_channel = LEDC_CHANNEL_0;
  c.ledc_timer = LEDC_TIMER_0;
  c.pin_d0 = Y2_GPIO_NUM;
  c.pin_d1 = Y3_GPIO_NUM;
  c.pin_d2 = Y4_GPIO_NUM;
  c.pin_d3 = Y5_GPIO_NUM;
  c.pin_d4 = Y6_GPIO_NUM;
  c.pin_d5 = Y7_GPIO_NUM;
  c.pin_d6 = Y8_GPIO_NUM;
  c.pin_d7 = Y9_GPIO_NUM;
  c.pin_xclk = XCLK_GPIO_NUM;
  c.pin_pclk = PCLK_GPIO_NUM;
  c.pin_vsync = VSYNC_GPIO_NUM;
  c.pin_href = HREF_GPIO_NUM;
  c.pin_sccb_sda = SIOD_GPIO_NUM;
  c.pin_sccb_scl = SIOC_GPIO_NUM;
  c.pin_pwdn = PWDN_GPIO_NUM;
  c.pin_reset = RESET_GPIO_NUM;
  c.xclk_freq_hz = 20000000;
  c.pixel_format = PIXFORMAT_GRAYSCALE;  // 灰階：每個像素一個位元組，0 黑、255 白
  c.frame_size = FRAMESIZE_QQVGA;        // 160×120，小張才算得快
  c.fb_count = 2;
  c.fb_location = CAMERA_FB_IN_PSRAM;
  c.grab_mode = CAMERA_GRAB_LATEST;
  esp_err_t err = esp_camera_init(&c);
  if (err != ESP_OK) {
    Serial.printf("相機啟動失敗：0x%x（排線沒插好，或開發板選錯）\n", err);
    return false;
  }
  return true;
}

void setup() {
  Serial.begin(115200);
  pinMode(RED_LED, OUTPUT);
  digitalWrite(RED_LED, HIGH);
  pinMode(FLASH_LED, OUTPUT);
  digitalWrite(FLASH_LED, LOW);

  prevFrame = (uint8_t *)malloc(W * H);
  if (!prevFrame || !initCamera()) {
    while (true) delay(1000);
  }
}

void loop() {
  camera_fb_t *fb = esp_camera_fb_get();
  if (!fb) return;
  if (fb->len != W * H) {  // 不是預期的大小就跳過
    esp_camera_fb_return(fb);
    return;
  }

  // 逐點比較：亮度差超過 PIXEL_DIFF 的像素有幾個
  int changed = 0;
  if (hasPrev) {
    for (int i = 0; i < W * H; i++) {
      if (abs((int)fb->buf[i] - (int)prevFrame[i]) > PIXEL_DIFF) changed++;
    }
  }
  memcpy(prevFrame, fb->buf, W * H);  // 這一張變成下一輪的「上一張」
  esp_camera_fb_return(fb);

  if (!hasPrev || millis() < WARMUP_MS) {
    hasPrev = true;
    delay(100);
    return;
  }

  float percent = changed * 100.0 / (W * H);
  Serial.printf("變化:%.1f 門檻:%.1f\n", percent, TRIGGER_PERCENT);  // 單位是 %

  if (percent > TRIGGER_PERCENT) {
    if (!moving) Serial.println("偵測到畫面變化");
    moving = true;
    lastMotion = millis();
  } else if (moving && millis() - lastMotion > HOLD_MS) {
    moving = false;
  }
  digitalWrite(RED_LED, moving ? LOW : HIGH);
  delay(100);
}

完成標準

按 RST，等 3 秒。打開序列繪圖家（Arduino IDE 右上角的折線圖示），鏡頭前不動時「變化」接近 0；在鏡頭前揮手，「變化」超過門檻線，紅燈亮起。

試試看

  • 打開或關掉房間的燈：整個畫面都變了，也會觸發。這就是畫面相減分不出「人在動」和「燈變了」。
  • 把 PIXEL_DIFF 調大，比較不會被雜訊觸發；把 TRIGGER_PERCENT 調小，比較小的動作也會觸發。

07

常見狀況

  • 序列埠一直印 Brownout detector was triggered，板子不停重開：電壓不夠。換一條短一點的 USB 線、直接插電腦（不要經過 USB 集線器），或改用 5V 2A 的充電器。AI 可能叫你在程式裡關掉這個偵測，這只是不讓它報錯，電壓還是不夠。
  • 相機啟動失敗：相機排線沒插到底，或排線插座的扣子沒扣上；程式裡的相機腳位不是 AI Thinker 的。
  • 畫面偏綠、偏紫，或上下顛倒：剛開機的前幾張還沒調好顏色，等幾秒；換過相機型號時要調整翻轉設定。
  • 板子很燙：串流時摸起來溫溫的是正常的。閃光燈長時間全亮會很燙，不要讓它一直亮；不要包在不透氣的盒子裡。
  • Wi-Fi 訊號弱、畫面一直卡：板子靠近路由器，天線那一端不要被金屬擋住。外接天線要改焊板子上的一顆小電阻，不是插上就有用。
  • 上傳一直失敗：照第 03 節按 IO0 和 RST 進入燒錄模式；還是不行，換一條能傳資料的 USB 線。

08

請 AI 幫你寫

你要準備
板子是 AI Thinker ESP32-CAM 加 ESP32-CAM-MB 底板、ESP32 開發板套件 3.3 版、要用的解析度、有沒有用記憶卡、要接哪些零件到哪幾支腳。
AI 能幫你
從本頁的範例改起：換解析度、加網址、加拍照的條件、把照片傳到別的地方；解釋序列埠印出的錯誤訊息。
怎麼查證
先燒範例 1 確認板子正常；相機腳位對照官方範例 camera_pins.h 裡的 CAMERA_MODEL_AI_THINKER；一次只改一個地方，改完就燒一次。
常見陷阱
  • AI 用 2.x 版的寫法（ledcSetup、ledcAttachPin），在 3.x 版編譯失敗。說清楚：我用的是 ESP32 Arduino 3.x 版。
  • 相機腳位用了 ESP-EYE 或 WROVER-KIT 的設定，相機啟動失敗。
  • 把 GPIO 0、16 或 U0R、U0T 拿去接零件。
  • 叫你在程式裡關掉 brownout 偵測，而不是處理電源。
