01

開始前

  • 電腦：Windows 10、11（64 位元）、macOS 12 以上，或 Linux（本講義以 Ubuntu、Debian 為例）。本講義只寫這三種電腦的做法。
  • 硬碟空間：至少留 10 GB。Arduino IDE 和 VS Code 加起來約 2 GB；ESP32 的開發板套件裝好約 5 GB，只用 Uno 可以不裝。
  • 網路：全部下載加起來好幾 GB，請用穩定、不限流量的網路。
  • 用自己的電腦：學校電腦可能沒有安裝軟體的權限，或裝了還原卡，重新開機後裝好的東西全部消失。
  • USB 傳輸線：有些 USB 線只能充電，不能傳資料。用這種線，板子的燈會亮，電腦卻找不到板子。買線時看清楚品名寫「傳輸」；手邊的線不確定時，換一條試。Mac 只有 USB-C 孔時，用 USB-C 轉接頭，或直接買 USB-C 接頭的線。

課程資料夾

下載 skilllab.zip，解壓縮後放到下面的位置。之後所有的 Python 程式、Arduino 程式都放在這個資料夾裡。

Windows

對 skilllab.zip 按右鍵 →「解壓縮全部」，目的地改成 C:\，就會得到 C:\skilllab。

macOS

雙擊 skilllab.zip，下載資料夾裡會出現 skilllab 資料夾。把它拖到個人專屬資料夾（Finder 按 Command＋Shift＋H 打開），位置是 ~/skilllab。

Linux

在檔案管理員對 skilllab.zip 按右鍵 →「解壓縮到此處」，再把 skilllab 資料夾移到家目錄，位置是 ~/skilllab。

路徑不要有中文、空格，也不要放在 OneDrive 會同步的資料夾（Windows 的「文件」「桌面」常常是）。

檔案用途
pyproject.toml這個資料夾要用的 Python 版本和套件
uv.lock每個套件的確切版本，全班裝到的都一樣
.python-versionPython 版本：3.13
.gitignore不放進 Git 的檔案：帳號密碼、虛擬環境
check_env.py環境驗收程式（第 07 節）
hello/hello.ino環境驗收用的 Arduino 範例

檔名開頭是「.」的檔案，macOS 和 Linux 預設會隱藏。Finder 按 Command＋Shift＋. 顯示；Linux 的檔案管理員按 Ctrl＋H。

02

Arduino IDE 與驅動程式

Arduino 程式用 Arduino IDE 寫和上傳；電腦要有 USB 驅動程式，才認得板子。

Windows 10、11

  1. Arduino IDE：到 arduino.cc/en/software 下載 Windows 版，執行安裝檔。安裝中問要不要安裝裝置軟體（USB 驅動程式）時，按「安裝」。
  2. 中文介面：介面是英文時，File → Preferences，Language 選中文（台灣），按 OK 後重新開啟。
  3. USB 驅動程式：插上板子，打開「裝置管理員」的「連接埠 (COM 和 LPT)」。看得到板子和 COM 編號（例如 COM3）就不用裝。沒有出現，或「其他裝置」裡有黃色驚嘆號的裝置，照下面的表找板子上的晶片，裝對應的驅動程式，再重新插一次 USB 線。

macOS

  1. Arduino IDE：到 arduino.cc/en/software 下載 macOS 版。Apple 晶片和 Intel 晶片各有一個版本，在「蘋果選單 → 關於這台 Mac」可以看到晶片。打開 .dmg，把 Arduino IDE 拖進「應用程式」資料夾。
  2. 中文介面：介面是英文時，Arduino IDE → Settings，Language 選中文（台灣），按 OK 後重新開啟。
  3. USB 驅動程式：macOS 內建 CH340、CH9102、CP2102 的驅動程式，插上就能用。到 Arduino IDE 的「工具 → 連接埠」找 /dev/cu. 開頭的名稱。找不到時，才裝下面表格裡的 macOS 驅動程式，裝完到「系統設定 → 隱私權與安全性」按「允許」，再重新開機。

Linux（以 Ubuntu、Debian 為例）

  1. Arduino IDE：到 arduino.cc/en/software 下載 Linux AppImage（64 位元）。AppImage 需要 FUSE：Ubuntu 24.04、Debian 13 以後安裝 libfuse2t64，更早的版本安裝 libfuse2。接著在下載資料夾打開終端機，讓檔案可以執行並開啟：
    終端機
    sudo apt install libfuse2t64
chmod +x arduino-ide_*_Linux_64bit.AppImage
./arduino-ide_*_Linux_64bit.AppImage

    出現 sandbox 相關的錯誤、開不起來時，在最後一行後面加上 --no-sandbox。

  2. 中文介面：介面是英文時，File → Preferences，Language 選中文（台灣），按 OK 後重新開啟。
  3. USB 驅動程式：原廠 Uno、CH340、CH9102、CP2102 都不用安裝，Linux 核心已經內建。
  4. 序列埠權限：把自己的帳號加入 dialout 群組，登出再登入後才會生效：
    終端機
    sudo usermod -a -G dialout $USER

板子上的 USB 晶片

晶片在 USB 孔旁邊，字很小，用手機拍照放大就看得清楚。

晶片常見在WindowsmacOSLinux
ATmega16U2原廠 Uno不用裝不用裝不用裝
CH340相容板 Uno、部分 ESP32CH341SER內建；找不到板子時裝 CH34xSER_MAC內建
CH9102新版 ESP32 DevKitCH343SER內建；找不到板子時裝 CH34xSER_MAC內建
CP2102ESP32 DevKitCP210x VCP內建；找不到板子時裝 CP210x VCP內建

Windows 看不出是哪個晶片時，在裝置管理員對那個裝置按右鍵 → 內容 → 詳細資料，選「硬體識別碼」：VID_1A86 是 WCH（PID_7523 是 CH340，PID_55D4 是 CH9102），VID_10C4 是 CP210x，VID_2341 是 Arduino 原廠。

連接埠名稱

  • Windows：COM 加一個數字，例如 COM3。
  • macOS：/dev/cu. 開頭，後面依晶片不同是 usbmodem 或 usbserial。
  • Linux：原廠 Uno 和 CH9102 是 /dev/ttyACM0，CH340 和 CP2102 是 /dev/ttyUSB0；接第二塊板子時，最後的數字變成 1。

ESP32 開發板套件

只用 Uno 可以跳過。在 Arduino IDE 左邊的「開發板管理員」搜尋 esp32，安裝「esp32 by Espressif Systems」3.3 開頭的最新版。裝好約 5 GB，下載要一段時間。

AI 寫的 ESP32 程式常用 2.x 版的寫法（例如 ledcSetup），在 3.x 版會編譯失敗。問 AI 時說清楚：我用的是 ESP32 Arduino 3.x 版。

確認

  1. 用 Arduino IDE 打開課程資料夾裡的 hello/hello.ino。
  2. 「工具 → 開發板」選你的板子：Uno 選 Arduino Uno；ESP32 DevKit 選 ESP32 Dev Module。
  3. 「工具 → 連接埠」選板子的連接埠，按上傳（向右的箭頭）。
  4. 上傳完成後打開「序列埠監控視窗」，速率是 9600，每秒出現一行 hello 和數字就成功。

ESP32 上傳時一直停在 Connecting…：按住板子上的 BOOT 鍵，看到開始寫入的百分比後再放開。

03

Python 與 uv

uv 一個工具管三件事：Python 本身的版本、每個資料夾自己的虛擬環境、套件和套件的版本。三個系統的指令都一樣。

版本不同，同一支程式的結果可能不同。例如 Python 3.15 版（2026 年 10 月發布）改了讀寫檔案的預設編碼，同一支程式在中文 Windows 上，換個版本結果就可能不同。課程固定用 Python 3.13，每個套件的版本記在 uv.lock，全班裝到的都一樣。

安裝 uv

Windows

從開始選單打開「PowerShell」，貼上這一行執行：

PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

裝完把 PowerShell 關掉，再開一個新的。

macOS

打開「終端機」App，貼上這一行執行：

終端機
curl -LsSf https://astral.sh/uv/install.sh | sh

裝完把終端機視窗關掉，再開一個新的。

Linux

打開終端機，先裝 curl，再裝 uv：

終端機
sudo apt install curl
curl -LsSf https://astral.sh/uv/install.sh | sh

裝完把終端機視窗關掉，再開一個新的。

確認裝好了：

終端機
uv --version

這種指令會從網路下載程式並執行。只貼官方網站給的指令（uv 的官方網站是 docs.astral.sh/uv），來路不明的不要貼。

在課程資料夾打開終端機

Windows

用檔案總管打開 C:\skilllab，在網址列輸入 powershell 後按 Enter。

macOS

打開終端機，輸入：

終端機
cd ~/skilllab

Linux

打開終端機，輸入：

終端機
cd ~/skilllab

第 04 節裝好 VS Code 之後，用 VS Code 裡的終端機更方便，它會直接開在課程資料夾。

裝好 Python 和套件

終端機
uv sync

第一次會下載 Python 3.13，以及 pyserial、requests、flask，裝進資料夾裡的 .venv。電腦原本有的 Python（包括 Anaconda）不會被改到。

執行 Python 程式

終端機
uv run check_env.py

每個專題的 Python 程式都放在課程資料夾，用 uv run 執行。三個系統都一樣，不用先啟用虛擬環境。這時板子還沒接也沒關係，序列埠和板子兩項到第 07 節再處理。

加套件

終端機
uv add 套件名稱

專題需要新套件時用 uv add，它會同時改 pyproject.toml 和 uv.lock。AI 叫你 pip install 時，也改用 uv add。uv 建的 .venv 裡沒有 pip，打 pip install 會裝到電腦裡別的 Python。

04

VS Code

VS Code 是寫 Python 的地方。Arduino 程式還是用 Arduino IDE 寫和上傳。

安裝

Windows

到 code.visualstudio.com 下載 Windows 版，執行安裝檔。「選擇其他工作」那一頁，「加入 PATH」保持勾選，兩個「Open with Code」（以 Code 開啟）也打勾。

macOS

到 code.visualstudio.com 下載 macOS 版，打開 .zip，把 Visual Studio Code 拖進「應用程式」資料夾。

Linux

到 code.visualstudio.com 下載 .deb，在下載資料夾打開終端機安裝：

終端機
sudo apt install ./code_*.deb

中文介面

左邊的 Extensions（四個方塊的圖示）搜尋 Chinese (Traditional)，安裝「Chinese (Traditional) Language Pack for Visual Studio Code」，按右下角的 Change Language and Restart。以下用中文介面的名稱。

延伸模組

延伸模組用途

Python（Microsoft）寫、執行、除錯 Python。會一起裝好 Pylance 和 Python Debugger。

Ruff（Astral）檢查程式碼、自動排好格式。

打開課程資料夾

  1. 「檔案 → 開啟資料夾」，選 skilllab。要開資料夾，不是只開一個檔案：只開檔案時，VS Code 不會用資料夾裡的 .venv。
  2. 問「您是否信任此資料夾中檔案的作者?」時，課程資料夾按「是，我信任作者」。來路不明的資料夾不要按信任。
  3. 打開 check_env.py，右下角的 Python 版本旁邊要看到 .venv。不是的話，按 Ctrl＋Shift＋P（macOS 是 Command＋Shift＋P）打開命令選擇區，輸入 Python: Select Interpreter，選有 .venv 的那一個。
  4. 「終端機 → 新增終端」會在下方開一個終端機，位置就在課程資料夾，uv 指令直接在這裡打。Windows 開的是 PowerShell。

確認

打開 check_env.py，按右上角的 ▶（執行 Python 檔案），下方終端機出現環境驗收的結果。

05

Git

Git 記錄資料夾裡檔案的變化：每一次「提交」都是一個存檔點。可以看兩個存檔點之間改了什麼，也可以退回去。

安裝

Windows

到 git-scm.com/downloads 下載 Git for Windows，安裝畫面大多照預設按 Next。選預設編輯器那一頁，改成「Use Visual Studio Code as Git's default editor」。裝完重新開啟 VS Code。

macOS

在終端機輸入下面這行。還沒裝 Git 時，會跳出視窗問要不要安裝命令列開發者工具，按「安裝」。

終端機
git --version

Linux

終端機
sudo apt install git

設定名字和信箱

每台電腦設定一次。存檔點會記下是誰提交的；以後要上傳 GitHub，信箱用 GitHub 帳號的信箱。

終端機
git config --global user.name "你的名字"
git config --global user.email "你的信箱"

在 VS Code 用 Git

  1. 建立存放庫：左邊的「原始檔控制」→「初始化存放庫」。.gitignore 已經排除 .venv 和 config.json，它們不會出現在變更清單裡。
  2. 提交：在訊息欄寫這次做了什麼，按「提交」。問「要暫存所有變更並直接提交嗎?」時按「是」。
  3. 看改了什麼：改過的檔案會出現在「原始檔控制」的變更清單，點一下會並排顯示改之前和改之後。
  4. 退回：對檔案按右鍵 →「捨棄變更」，檔案回到上一個存檔點的樣子。

上傳 GitHub（「發布分支」）之前確認兩件事：存放庫選私人；變更清單裡沒有 config.json。公開存放庫裡的密碼，很快就會被自動掃描的程式找到並拿去用。

確認

「原始檔控制」裡有第一個提交，訊息寫「課程資料夾」。

06

AI 工具與資安

AI 有兩種用法，差別在它碰得到你電腦裡的多少東西。

  • 對話：只看得到你貼上去的內容。
  • 代理：看得到整個資料夾裡的檔案，會改檔案，也會要求執行指令。
對話代理費用
Codex（OpenAI）ChatGPT 網頁、AppVS Code 延伸模組「Codex」（發行者 OpenAI）、Codex App用 ChatGPT 帳號登入；免費方案有用量限制
Claude（Anthropic）claude.ai 網頁、AppVS Code 延伸模組「Claude Code」（發行者 Anthropic）、終端機對話有免費方案；Claude Code 要 Pro 以上的付費方案

方案和用量限制常常改變，以官方網站為準。

代理裝在 VS Code：「延伸模組」搜尋 Codex 或 Claude Code，認明發行者後安裝，照畫面登入帳號。

資安

  1. 密碼、金鑰不貼給 AI：Gmail 應用程式密碼、Discord Webhook 網址、Wi-Fi 密碼、API 金鑰都放在 config.json；給 AI 看的是 config.example.json。
  2. 代理看得到 config.json：代理讀得到整個課程資料夾，所以 config.json 只放可以撤銷的東西。Gmail 用應用程式密碼，不用帳號本身的密碼；專題通知另外開一個 Gmail 帳號；課程結束就撤銷應用程式密碼、刪掉 Webhook。
  3. 權限不要全開：Codex 不要選完整存取（Full access），Claude Code 不要開略過權限（bypass permissions）。代理要執行指令時，看懂再按允許；sudo、刪除檔案、curl … | sh、安裝套件這幾種要特別看。
  4. AI 建議的套件先查：到 pypi.org 確認套件真的存在、名字沒有拼錯。有人專門註冊和熱門套件名字很像的假套件。Arduino 程式庫從 Arduino IDE 的「程式庫管理員」安裝。
  5. 只從官方網站下載：軟體和驅動程式用本講義各步驟裡的連結；搜尋結果裡的驅動程式下載站，可能夾帶其他程式。
  6. 先看差異再保留：代理改完程式，到「原始檔控制」看改了哪些地方；看不懂或改壞了就「捨棄變更」。
  7. 不貼個資：自己和別人的姓名、電話、照片、學號都不要貼給 AI。
  8. 共用電腦用完要登出：在學校電腦登入 AI 帳號，離開前登出。

確認

  1. 請 AI 把 hello/hello.ino 改成每 2 秒印一次。
  2. 在「原始檔控制」看它改了哪幾行。
  3. 對 hello.ino 按「捨棄變更」，回到原本的樣子。

07

環境驗收

  1. 板子燒好 hello 範例（第 02 節），USB 線接著。
  2. 關掉 Arduino IDE 的序列埠監控視窗，序列埠同一時間只能給一個程式用。
  3. 在 VS Code 的終端機執行：
    終端機
    uv run check_env.py
  4. 最後一行是「全部通過。」就完成了。
輸出範例

預設文字編碼：cp950（讀寫檔案時要寫 encoding="utf-8"，含中文的檔案才不會出錯）
[通過] Python：3.13.16（.venv）
[通過] 套件：pyserial 3.5、requests 2.34.2、flask 3.1.3

有 [失敗] 或 [注意] 時，照 → 後面的說明做。要求救時，把整段輸出貼給老師或 AI，裡面沒有帳號密碼。

全部通過後，在「原始檔控制」提交一次，訊息寫「環境驗收通過」。

check_env.py

環境驗收程式的內容，在課程資料夾裡已經有了。

程式碼check_env.py
check_env.py180 行
"""
環境驗收：檢查 Python、套件、Gmail 連線、序列埠和板子，並顯示預設文字編碼
執行：uv run check_env.py [--port 序列埠]
板子要先燒好 hello 範例。輸出裡沒有帳號密碼，可以整段貼給老師或 AI。
"""

import argparse
import importlib.metadata
import locale
import platform
import smtplib
import socket
import ssl
import sys
import time
from pathlib import Path

PYTHON_VERSION = (3, 13)
PACKAGES = ["pyserial", "requests", "flask"]
BAUD = 9600
WAIT_SECONDS = 6

# USB 晶片的廠商代碼（VID）和產品代碼（PID）
CHIPS = {
    (0x1A86, 0x7523): "CH340",
    (0x1A86, 0x55D4): "CH9102",
    (0x10C4, 0xEA60): "CP2102",
}
VENDORS = {
    0x2341: "Arduino 原廠",
    0x2A03: "Arduino 原廠",

def report(ok, item, detail, fix=None):
    """ok：True 通過、None 注意、False 失敗"""
    global problems
    mark = {True: "[通過]", None: "[注意]", False: "[失敗]"}[ok]
    if ok is not True:
        problems += 1
    print(f"{mark} {item}：{detail}")
    if fix:
        print(f"       → {fix}")


def check_python():
    v = sys.version_info
    in_venv = sys.prefix != sys.base_prefix
    where = Path(sys.prefix).name if in_venv else "不在虛擬環境"
    detail = f"{v.major}.{v.minor}.{v.micro}（{where}）"
    if (v.major, v.minor) != PYTHON_VERSION:
        report(False, "Python", detail, "在課程資料夾執行 uv sync，再用 uv run 執行這個檔案")
    elif not in_venv:
        report(None, "Python", detail, "用 uv run check_env.py 執行，才會用到課程資料夾的 .venv")
    else:
        report(True, "Python", detail)


def check_packages():
    found, missing = [], []
    for name in PACKAGES:
        try:
            found.append(f"{name} {importlib.metadata.version(name)}")
        except importlib.metadata.PackageNotFoundError:
            missing.append(name)
    if missing:
        report(False, "套件", "缺少 " + "、".join(missing), "在課程資料夾執行 uv sync")
    else:
        report(True, "套件", "、".join(found))

def check_gmail():
    try:
        with smtplib.SMTP_SSL("smtp.gmail.com", 465,
                              context=ssl.create_default_context(), timeout=10) as server:
            server.noop()
        report(True, "Gmail 連線", "smtp.gmail.com:465，憑證正常")

def chip_name(p):
    if p.vid is None:
        return ""
    name = CHIPS.get((p.vid, p.pid)) or VENDORS.get(p.vid, "")
    return f"{name}，{p.vid:04X}:{p.pid:04X}" if name else f"{p.vid:04X}:{p.pid:04X}"


def check_board(port_arg):
    try:
        import serial
        import serial.tools.list_ports
    except ImportError:
        report(False, "序列埠", "沒有 pyserial，無法檢查", "在課程資料夾執行 uv sync")
        return

    # 只看 USB 裝置；macOS 的藍牙、除錯埠沒有 VID，會被排除
    ports = [p for p in serial.tools.list_ports.comports() if p.vid is not None]
    for p in ports:
        print(f"       {p.device}　{p.description}（{chip_name(p)}）")

    if port_arg:
        port = port_arg
    elif not ports:
        report(False, "序列埠", "沒有找到 USB 序列埠",
               "換一條確定能傳資料的 USB 線；再確認 USB 驅動程式有裝好")
        return
    elif len(ports) > 1:
        report(None, "序列埠", f"找到 {len(ports)} 個，不知道要用哪一個",
               "拔掉其他板子，或加上 --port 指定，例如 uv run check_env.py --port COM3")
        return
    else:
        port = ports[0].device
    report(True, "序列埠", port)

    try:
        with serial.Serial(port, BAUD, timeout=1) as ser:
            # 打開序列埠時 Uno 會重新開機，等它送出 hello
            deadline = time.time() + WAIT_SECONDS
            other = ""
            while time.time() < deadline:
                line = ser.readline().decode("utf-8", errors="replace").strip()
                if line.startswith("hello"):
                    report(True, "板子", f"收到「{line}」")
                    return
                if line and not other:
                    other = line
        if other:
            report(None, "板子", f"有收到資料，但不是 hello：「{other[:40]}」",
                   "板子燒的不是 hello 範例，或範例的速率不是 9600")
        else:
            report(False, "板子", f"{WAIT_SECONDS} 秒內沒有收到資料",
                   "先在 Arduino IDE 把 hello 範例上傳到板子")
    except serial.SerialException as e:
        text = str(e)
        if any(s in text for s in ("denied", "Permission", "存取被拒", "Errno 13", "busy")):
            report(False, "板子", "序列埠打不開（被拒絕）",
                   "關掉 Arduino IDE 的序列埠監控視窗；Linux 要加入 dialout 群組後重新登入")
        else:
            report(False, "板子", f"序列埠打不開：{text}", "重新插拔 USB 線，再執行一次")

常見問題

每一條先寫看到什麼，再寫原因和處理方法。

全部的系統
  • 板子的燈會亮，電腦卻找不到板子：用到只能充電的 USB 線。換一條傳輸線。
  • ESP32 上傳停在 Connecting…，最後出現 Failed to connect to ESP32：板子沒有進入燒錄模式。看到 Connecting… 時按住 BOOT 鍵，開始寫入後再放開。
  • No module named 'serial'（或其他套件名稱）：沒有用 uv run 執行，或課程資料夾還沒執行 uv sync。在課程資料夾執行 uv sync，再用 uv run 執行。
  • pip install 了，還是說找不到套件：pip 把套件裝到電腦裡別的 Python。改用 uv add 套件名稱。
  • 'ledcSetup' was not declared in this scope：AI 寫的是 ESP32 2.x 版的寫法。告訴 AI「我用的是 ESP32 Arduino 3.x 版」，請它改寫。
  • 序列埠監控視窗出現亂碼：視窗的速率和程式裡 Serial.begin 的數字不一樣。hello 範例用 9600。
  • [失敗] Gmail 連線：連不上：網路不通，或學校、公司的網路擋了 465 埠。換手機熱點再試一次。
Windows
  • 輸入 uv 出現「無法辨識 'uv' 詞彙」：裝完 uv 還沒重開 PowerShell 或 VS Code。全部關掉再打開。
  • VS Code 的終端機出現「因為這個系統上已停用指令碼執行」：VS Code 想自動啟用虛擬環境，被 PowerShell 的安全設定擋下。不影響 uv run，可以不理它。
  • 裝置管理員出現有黃色驚嘆號的「USB2.0-Serial」：CH340 的驅動程式還沒裝。照第 02 節的表安裝。
  • 打不開序列埠，訊息有「存取被拒」：序列埠監控視窗或另一個程式正在用這個序列埠。關掉它再試。
  • Windows on ARM 筆電（Snapdragon）找不到 CH340 的板子：舊版 CH340 驅動程式不支援 ARM。到 WCH 官網下載 3.9 以上的版本。
  • 讀檔出現 UnicodeDecodeError: 'cp950' codec：open() 沒有寫 encoding="utf-8"。加上 encoding="utf-8"。
macOS
  • 輸入 uv 出現 command not found：裝完 uv 還沒開新的終端機視窗。關掉再開一個。
  • 連接埠清單裡只有 /dev/cu.Bluetooth-Incoming-Port：電腦沒有認到板子。換一條傳輸線；USB-C 轉接頭或集線器也換一個試。
  • 出現 CERTIFICATE_VERIFY_FAILED：用的不是 uv 裝的 Python。在課程資料夾用 uv run 執行。
  • 用 localhost:5000 打開網頁看到 403：macOS 的 AirPlay 接收器佔用 5000 埠。網頁程式改用 8000 埠。
Linux
  • 燒錄或打開序列埠出現 Permission denied：還沒加入 dialout 群組，或加入後還沒登出再登入。
  • CH340 的 /dev/ttyUSB0 出現一下又消失：brltty（點字顯示器程式）把裝置搶走了。沒有用點字顯示器的話，執行 sudo apt remove brltty。
  • Arduino IDE 的 AppImage 打不開：缺少 FUSE，或 sandbox 的限制。照第 02 節安裝 libfuse2t64，或在指令後面加上 --no-sandbox。
  • 輸入 uv 出現 command not found：裝完 uv 還沒開新的終端機視窗。關掉再開一個。
