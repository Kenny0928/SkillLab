影像辨識

電腦看到的只是一格一格的數字。從像素和顏色開始，認識現在常見的辨識方法、它們各自回答什麼問題，以及什麼時候會看錯。

01

電腦看到的是什麼

  • 解析度：橫向和直向各有幾個像素。640×480 的照片有 307,200 個像素，每個像素 3 個數字，一張就有九十多萬個數字。
  • 每秒張數（fps）：影片和串流是一張一張的照片連續送出。辨識的程式每秒處理得了幾張，決定它反應有多快。
  • 灰階：每個像素只留一個亮度數字（0 黑、255 白）。資料少三分之二，適合只在乎亮暗變化的時候。
  • JPEG 壓縮：640×480 的照片原本約 900 KB，壓成 JPEG 通常只剩幾十 KB。ESP32-CAM 送出來的就是 JPEG，到了電腦再解壓回像素。
解析度名稱像素什麼時候用
160×120QQVGA約 1.9 萬板子上自己算：顏色篩選、畫面變化
320×240QVGA約 7.7 萬串流要順、網路比較慢
640×480VGA約 31 萬送到電腦做 AI 辨識，速度和細節的折衷
1600×1200UXGA約 192 萬拍照存檔；ESP32-CAM 的最大解析度

解析度越高，細節越多，但傳得慢、算得慢。遠處的人在 160×120 的畫面裡可能只有幾個像素高，任何方法都認不出來。

02

不用 AI 的方法

AI 出現以前，影像辨識靠人寫規則：「橘色的像素」「和上一張不一樣的像素」。這些方法很快、不用訓練，連 ESP32-CAM 這種小板子都跑得動。條件單純的時候，它們常常比 AI 好用。

HSV：用顏色找東西

想找出畫面裡的橘色乒乓球，直覺是看 RGB。問題是同一顆球，照到光和在陰影裡，RGB 三個數字全部都變了。換成 HSV，顏色和亮度就分開了：

顏色RGBHSV（OpenCV）
照到光228, 87, 467, 204, 228
在陰影裡146, 62, 387, 189, 146
  • H 色相：是什麼顏色。上面兩格的 H 都是 7，都是橘色。
  • S 飽和度：顏色有多鮮豔。白、灰、黑的 S 很低。
  • V 明度：有多亮。陰影主要改變的是 V。

所以找橘色的球，只要設定「H 在 5 到 20 之間、S 和 V 不能太低」，照到光和在陰影裡的部分都會被選到。

顏色H 大約在
紅0–10 和 170–179（跨過 0，要分兩段）
橘10–25
黃25–35
綠35–85
藍100–130
紫130–160

OpenCV 的 H 是 0–179：色相原本是 0–360 度，除以 2 才放得進 0–255。繪圖軟體和網路上的取色器多半用 0–360，數字要先除以 2。表上的範圍只是起點，實際要在現場對著東西調。

做法是五個步驟：

  1. 把畫面從 RGB 轉成 HSV。
  2. 設定 H、S、V 的上下限，範圍內的像素變白、其他變黑，得到一張黑白的「遮罩」。
  3. 去掉零星的白點（雜訊）。
  4. 找出最大的一塊白色區域。
  5. 算出它的中心點和面積：中心點告訴你東西在哪裡，面積大致告訴你多近。

第 07 節的程式有 HSV 模式，用滑桿調範圍、在畫面上點一下就看得到那一點的 HSV。

畫面相減：找出哪裡在動

把現在的畫面和上一張逐點相減，亮度差很多的像素就是「有變化」。變化的像素超過一定比例，就判定畫面裡有東西在動。ESP32-CAM 講義的範例 5 就是在板子上這樣做。

這兩種方法做不到的

  • HSV 只認顏色：背景有同樣顏色的東西就會選錯；黃色燈光會把白色變成黃色；白、灰、黑的 H 不穩定，只能靠 S 和 V 分。
  • 畫面相減只知道「有變化」，不知道是什麼在動：人走過、開燈、窗簾被風吹、相機自動調整亮度，對它來說都一樣。
  • 兩種方法都不知道「人」是什麼。要分辨人、貓、車，就需要 AI。

03

AI 能做的五種事

AI 模型不是靠人寫規則，而是看過大量標好答案的照片，自己學出「人長什麼樣子」。同一張畫面，依照任務不同，模型給的答案也不同：

任務輸出適合回答本課用的模型
影像分類一個類別和信心度畫面裡主要是什麼？有沒有某種東西？yolo26n-cls.ptImageNet 1000 類
物件偵測每個物體一個框、類別、信心度有幾個人？在畫面的哪裡？yolo26n.ptCOCO 80 類
實例分割每個物體的輪廓形狀和面積，例如水果有多大yolo26n-seg.ptCOCO 80 類
語意分割每個像素的類別沒有固定形狀的區域：路面、天空、草地yolo26n-sem.ptCityscapes 19 類街景
姿勢辨識每個人 17 個關節點的位置舉手、跌倒、運動動作對不對yolo26n-pose.ptCOCO 人體關節點

本課用 Ultralytics 的 YOLO26（2026 年 1 月發布），五種任務用同一套程式寫法，只換模型檔。檔名的 n 是最小的版本，一般筆電不用顯示卡也跑得動。

還有這些

  • 人臉偵測和人臉辨識：偵測是「這裡有一張臉」；辨識是「這是誰」。辨識需要先登記每個人的臉，臉部特徵屬於個人資料，用之前要取得當事人同意。
  • 文字辨識（OCR）：把照片裡的文字讀成文字，例如車牌、標籤。
  • 用文字描述畫面：多模態大型語言模型（例如 Claude、ChatGPT、Gemini）可以回答「畫面裡的人在做什麼」這種開放的問題，但要上傳到雲端，一張要零點幾秒到幾秒。

04

看懂辨識結果

把一張 1280×720 的照片（兩個人，其中一個打領帶）交給 yolo26n.pt 做物件偵測，得到三筆結果：

類別信心度框（x1, y1, x2, y2）
person0.89742, 40, 1150, 708
person0.84118, 201, 1002, 712
tie0.58436, 434, 525, 715
  • 類別：模型認得的名稱之一，是英文。COCO 的 80 類裡有 person、cat、dog、car、cup、cell phone，沒有「安全帽」「乒乓球」（球都算 sports ball）。
  • 信心度：0 到 1，模型自己覺得有多像。它不是「答對的機率」：模型也可能很有信心地認錯。
  • 框：左上角（x1, y1）和右下角（x2, y2），單位是像素。原點在畫面左上角，x 往右變大，y 往下變大。中心點是 ((x1+x2)/2, (y1+y2)/2)；框越大，通常代表越近。

門檻：誤報和漏報的取捨

程式只留下信心度超過門檻的結果。同一張照片：

門檻留下的結果
0.25–0.4person、person、tie
0.6 以上person、person（領帶不見了）

門檻調高，誤報變少，漏報變多；調低則相反。這和簡易防盜系統調觸發距離是同一件事，兩個數字要一起看。

一張準，不代表每一張都準

同一個人站著不動，連續幾張畫面裡，信心度也會在門檻上下跳，這一張有、下一張沒有。所以實際的系統不會看到一次就發通知，而是「連續幾張都有」才算數，發過通知後再等一段冷卻時間。微專題 02 的判斷就是在做這件事。

05

模型從哪裡來

模型是用「資料集」訓練出來的：大量照片，每一張都由人標好答案（類別、框、輪廓或關節點）。模型只認得訓練時看過的類別。

資料集內容要注意
ImageNet約 128 萬張訓練照片，1000 類，用在影像分類1000 類裡沒有「人」。拿人的照片去分類，答案會是 suit（西裝）、sweatshirt（運動衫）這種衣服
COCO約 12 萬張訓練照片，80 類日常物品，標了框、輪廓和人體關節點大多是平視的生活照；監視器常從高處往下拍，角度和訓練照片不同
Cityscapes歐洲城市的街景，5,000 張逐像素標註，常用 19 類只學過街景，對著室內會把牆認成 building、地板認成 road

要認的東西不在清單裡

  • 影像分類：Teachable Machine 在瀏覽器裡用鏡頭拍幾十張照片就能訓練，例如「有戴安全帽／沒戴安全帽」。不用寫程式、不用登入。
  • 物件偵測：自己拍照、一張一張框出目標，再用 Ultralytics 從已經訓練好的模型接著訓練。每一類至少要幾百張，而且要包含不同光線、角度和背景。

訓練資料決定了模型的盲點

訓練照片裡少見的情況，模型就表現差：夜間、逆光、特殊角度、特殊服裝，以及在資料集裡出現得比較少的族群和膚色。模型在你的場地準不準，要在你的場地測過才知道。

06

在哪裡跑

同樣是「看到人就通知」，辨識可以放在三個地方：

板子上電腦上雲端
例子ESP32-S3、XIAO ESP32-S3 Sense、AMB82-mini筆電跑 YOLO26（微專題 02）雲端影像辨識服務、多模態大型語言模型
模型很小：類別少、解析度低中小型，每秒十幾到幾十張最大，能用文字描述畫面
反應時間最快快，畫面要先從板子傳到電腦慢，要上傳、排隊，一張零點幾秒到幾秒
網路不需要板子和電腦要在同一個網路要能上網
費用只有硬體電腦要一直開著依用量收費，要保管金鑰
隱私影像不離開板子影像留在自己的電腦影像傳到別人的伺服器

ESP32-CAM 用的是經典款 ESP32，只能做顏色篩選、畫面相減這類簡單的運算，所以微專題 02 讓 ESP32-CAM 負責拍、電腦負責辨識。各種板子的比較見選擇控制器講義。

07

自己試試看

vision_demo.py 用電腦的鏡頭，在同一個畫面上切換六種方法：HSV 和第 03 節的五種 AI 任務。

安裝

先照環境安裝講義建好課程資料夾，再在課程資料夾的終端機執行：

終端機
uv add ultralytics

ultralytics 會一起裝 PyTorch 和 OpenCV，裝好約 1 GB，下載要好幾分鐘，請在上課前裝好。每種方法第一次使用時，還會自動下載 3–8 MB 的模型檔到課程資料夾。

執行

終端機
uv run vision_demo.py
  • 按 1–6 切換：1 HSV、2 影像分類、3 物件偵測、4 實例分割、5 語意分割、6 姿勢辨識。按 Q 結束。
  • 終端機每秒印一次結果，例如「detect：person ×1、cup ×1」。
  • HSV 模式會多開一個視窗，上面有滑桿和黑白遮罩。在畫面上點一下，終端機會印出那一點的 HSV。

不用電腦鏡頭，改用一張照片，或 ESP32-CAM 的畫面（板子要先燒範例 3，IP 換成序列埠印出的）：

終端機
uv run vision_demo.py --source 照片.jpg
uv run vision_demo.py --source http://192.168.1.23/capture
教學打不開鏡頭：允許終端機使用相機
  • macOS：第一次執行會問「終端機想要取用相機」，按允許。按了不允許的話，到「系統設定 → 隱私權與安全性 → 相機」，打開「終端機」或「Visual Studio Code」，再重新打開終端機。
  • Windows：到「設定 → 隱私權與安全性 → 相機」，打開「相機存取」和「讓桌面應用程式存取您的相機」。
  • 視訊會議軟體（Teams、Meet、LINE）開著的時候，鏡頭可能被它佔用，先關掉。
  • 筆電接了外接鏡頭時，用 --source 1 試第二支。

程式

存成課程資料夾裡的 vision_demo.py。

vision_demo.py239 行
"""
影像辨識試驗台：同一個畫面，試六種辨識方法
執行：uv run vision_demo.py [--source 來源] [--task 方法]（在課程資料夾裡執行）
  --source  0：電腦鏡頭（預設）；1：第二支鏡頭
            http://ESP32-CAM的IP/capture：ESP32-CAM（範例 3 的程式）
            圖片或影片檔的路徑
  --task    hsv、classify、detect、segment、semantic、pose（預設 detect）
畫面上按 1–6 切換方法，按 Q 或 Esc 結束。
HSV 模式：用 HSV 視窗的滑桿調範圍；在畫面上點一下，終端機會印出那一點的 HSV。
需要套件：ultralytics（uv add ultralytics）。每種方法第一次用，會自動下載模型到課程資料夾。
"""

import argparse
import time
from pathlib import Path

import cv2
import numpy as np
import requests
from ultralytics import YOLO

WIN = "vision"
HSV_WIN = "HSV"
TASKS = ["hsv", "classify", "detect", "segment", "semantic", "pose"]  # 對應按鍵 1–6

# 每種方法用的模型：Ultralytics YOLO26 最小的 n 版，一般筆電不用顯示卡也跑得動
MODELS = {
    "classify": "yolo26n-cls.pt",  # 影像分類：ImageNet 1000 類，整張圖一個答案
    "detect": "yolo26n.pt",        # 物件偵測：COCO 80 類，每個物體一個框
    "segment": "yolo26n-seg.pt",   # 實例分割：COCO 80 類，每個物體描出輪廓
    "semantic": "yolo26n-sem.pt",  # 語意分割：Cityscapes 19 類（街景），每個像素一個類別
    "pose": "yolo26n-pose.pt",     # 姿勢辨識：每個人 17 個關節點
}
CONF = 0.4  # 信心度低於這個值的結果不畫

# HSV 滑桿的初始值：橘色乒乓球。OpenCV 的 H 是 0–179（色相角度除以 2），S、V 是 0–255
HSV_START = {"H min": 5, "H max": 20, "S min": 120, "V min": 120}
HSV_MAX = {"H min": 179, "H max": 179, "S min": 255, "V min": 255}

IMAGE_EXT = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}

models = {}               # 載入過的模型，切回來不用重新載入
last = {"frame": None}    # 最新的原始畫面，給滑鼠點擊查 HSV 用


# ---------- 畫面來源 ----------

class Source:
    """電腦鏡頭、ESP32-CAM 網址、圖片、影片，都用 read() 拿一張畫面。"""

    def __init__(self, src: str):
        self.cap = None
        self.url = None
        self.image = None
        if src.isdigit():
            self.cap = cv2.VideoCapture(int(src))
        elif src.startswith("http") and src.rstrip("/").endswith("/capture"):
            self.url = src  # 每次要一張最新的
        elif Path(src).suffix.lower() in IMAGE_EXT:
            self.image = cv2.imread(src)
            if self.image is None:
                raise SystemExit(f"讀不到圖片：{src}")
        else:
            self.cap = cv2.VideoCapture(src)  # 影片檔，或 ESP32-CAM 的 :81/stream
        if self.cap is not None and not self.cap.isOpened():
            raise SystemExit(f"打不開 {src}：鏡頭被別的程式用著、編號不對、檔案不存在，或網址打錯")

    def read(self):
        if self.image is not None:
            return self.image.copy()
        if self.url:
            try:
                r = requests.get(self.url, timeout=5)
                r.raise_for_status()
            except requests.RequestException as e:
                print(f"拿不到畫面：{e}")
                return None
            return cv2.imdecode(np.frombuffer(r.content, np.uint8), cv2.IMREAD_COLOR)
        ok, frame = self.cap.read()
        return frame if ok else None

    def close(self):
        if self.cap is not None:
            self.cap.release()


# ---------- 傳統方法：HSV 顏色篩選 ----------

def hsv_mask(frame, h_min, h_max, s_min, v_min):
    """回傳黑白遮罩：顏色在範圍內的像素是白色（255）。"""
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    if h_min <= h_max:
        mask = cv2.inRange(hsv, (h_min, s_min, v_min), (h_max, 255, 255))
    else:
        # 紅色跨過 0：H ≥ h_min 或 H ≤ h_max 都算
        mask = (cv2.inRange(hsv, (h_min, s_min, v_min), (179, 255, 255))
                | cv2.inRange(hsv, (0, s_min, v_min), (h_max, 255, 255)))
    # 先縮再脹，去掉零星的雜點
    return cv2.morphologyEx(mask, cv2.MORPH_OPEN, np.ones((5, 5), np.uint8))


def run_hsv(frame, h_min, h_max, s_min, v_min):
    mask = hsv_mask(frame, h_min, h_max, s_min, v_min)
    out = (frame * 0.3).astype(np.uint8)  # 不符合的地方變暗
    out[mask > 0] = frame[mask > 0]
    summary = "沒有找到這個顏色"
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    if contours:
        biggest = max(contours, key=cv2.contourArea)
        area = cv2.contourArea(biggest)
        if area > 200:  # 太小的當作雜訊
            x, y, w, h = cv2.boundingRect(biggest)
            cx, cy = x + w // 2, y + h // 2
            cv2.rectangle(out, (x, y), (x + w, y + h), (0, 255, 0), 2)
            cv2.circle(out, (cx, cy), 5, (0, 0, 255), -1)
            summary = f"最大的一塊：中心 ({cx}, {cy})，面積 {int(area)} 像素"
    return out, mask, summary


def read_sliders():
    return [cv2.getTrackbarPos(name, HSV_WIN) for name in HSV_START]


def open_hsv_window():
    cv2.namedWindow(HSV_WIN)
    for name, value in HSV_START.items():
        cv2.createTrackbar(name, HSV_WIN, value, HSV_MAX[name], lambda v: None)


def on_click(event, x, y, flags, param):
    frame = last["frame"]
    if event == cv2.EVENT_LBUTTONDOWN and frame is not None:
        h, s, v = cv2.cvtColor(frame[y:y + 1, x:x + 1], cv2.COLOR_BGR2HSV)[0, 0]
        print(f"({x}, {y}) 的 HSV：H={h} S={s} V={v}")


# ---------- AI 方法：YOLO26 ----------

def get_model(task):
    if task not in models:
        print(f"載入 {MODELS[task]}（第一次會下載）……")
        models[task] = YOLO(MODELS[task])
    return models[task]


def summarize(task, res):
    """把辨識結果整理成一行文字。"""
    names = res.names
    if task == "classify":
        top = res.probs.top5[:3]
        return "、".join(f"{names[i]} {float(res.probs.data[i]):.2f}" for i in top)
    if task == "semantic":
        classes, counts = np.unique(res.semantic_mask.data.cpu().numpy(), return_counts=True)
        share = sorted(zip(counts, classes), reverse=True)[:3]
        total = counts.sum()
        return "、".join(f"{names[int(c)]} {n / total:.0%}" for n, c in share)
    if res.boxes is None or len(res.boxes) == 0:
        return "沒有偵測到"
    found = {}
    for c in res.boxes.cls.tolist():
        found[names[int(c)]] = found.get(names[int(c)], 0) + 1
    text = "、".join(f"{name} ×{n}" for name, n in found.items())
    if task == "pose":
        text += f"（每人 {res.keypoints.shape[1]} 個關節點）"
    return text


def run_model(task, frame):
    res = get_model(task)(frame, conf=CONF, verbose=False)[0]
    return res.plot(), summarize(task, res)

def label(img, text):
    """左上角寫字：先畫黑色粗字當外框，再畫白字。"""
    for color, thick in (((0, 0, 0), 5), ((255, 255, 255), 2)):
        cv2.putText(img, text, (12, 32), cv2.FONT_HERSHEY_SIMPLEX, 0.8, color, thick, cv2.LINE_AA)


def main():
    parser = argparse.ArgumentParser(description="影像辨識試驗台")
    parser.add_argument("--source", default="0", help="0、1、ESP32-CAM 的 /capture 網址、圖片或影片檔")
    parser.add_argument("--task", default="detect", choices=TASKS)
    args = parser.parse_args()

    src = Source(args.source)
    task = args.task
    cv2.namedWindow(WIN)
    cv2.setMouseCallback(WIN, on_click)
    if task == "hsv":
        open_hsv_window()
    print("按 1–6 切換：1 HSV、2 分類、3 偵測、4 實例分割、5 語意分割、6 姿勢。按 Q 結束。")

    fails = 0
    last_print = 0.0
    while True:
        frame = src.read()
        if frame is None:
            fails += 1
            if fails >= 10:
                print("連續 10 次沒有畫面，結束")
                break
            time.sleep(0.5)
            continue
        fails = 0
        last["frame"] = frame

        start = time.perf_counter()
        if task == "hsv":
            out, mask, summary = run_hsv(frame, *read_sliders())
            cv2.imshow(HSV_WIN, mask)
        else:
            out, summary = run_model(task, frame)
        fps = 1 / max(time.perf_counter() - start, 1e-6)

        label(out, f"[{TASKS.index(task) + 1}] {task}  {fps:.1f} fps")
        cv2.imshow(WIN, out)
        if time.time() - last_print >= 1:  # 每秒印一次結果
            print(f"{task}：{summary}")
            last_print = time.time()

        key = cv2.waitKey(1) & 0xFF
        if key in (ord("q"), ord("Q"), 27):
            break
        if ord("1") <= key <= ord("6"):
            new_task = TASKS[key - ord("1")]
            if new_task == "hsv" and task != "hsv":
                open_hsv_window()
            elif task == "hsv" and new_task != "hsv":
                cv2.destroyWindow(HSV_WIN)
            task = new_task

    src.close()
    cv2.destroyAllWindows()


if __name__ == "__main__":
    main()

試試這些

  1. HSV：調到只剩手上的一樣東西被選到。換到窗邊或關掉一盞燈，看範圍還準不準。
  2. 影像分類：對著自己，答案是什麼？為什麼不是 person？
  3. 物件偵測：慢慢往後退，看框變小、信心度什麼時候掉到門檻以下。用手遮住半張臉再試一次。
  4. 實例分割和語意分割：找另一個人一起入鏡，比較兩種分割怎麼處理兩個人。
  5. 姿勢辨識：舉起右手，看手腕的點有沒有跑到肩膀上面。這就是「偵測舉手」的判斷方法。
  6. 對著手機螢幕上的人物照片，物件偵測會不會把它當成人？

08

什麼情況下會看錯

「我的辨識在什麼狀況下會翻車？」

拍攝條件

  • 太暗或逆光：細節不見了，人變成一團黑影，漏報。ESP32-CAM 這類小相機在暗處特別明顯。
  • 動作太快：畫面模糊，認不出來。
  • 東西太小或太遠：只佔幾個像素，什麼方法都認不出來。
  • 被遮住一半、角度特殊：從正上方往下拍、只拍到背影或半身，信心度會掉很多。

模型本身

  • 照片、海報、螢幕裡的人：模型分不出是真人還是圖片，一樣會偵測到。
  • 鏡子和玻璃的倒影：同一個人被算成兩個。
  • 不在清單裡的東西：模型不會說「不認得」，而是歸到最像的類別，或乾脆不理它。
  • 訓練資料裡少見的情況：特殊服裝、夜間、特殊族群，準確度比平常低。
  • 信心度高不等於對：模型可能以 0.9 的信心度認錯。

不用 AI 的方法

  • HSV 碰到同色的背景，或燈光的顏色改變：選錯，或找不到。
  • 畫面相減碰到開燈、窗簾晃動、相機自動曝光：整個畫面都在變，誤報。

這些情況不能靠「換一個更大的模型」全部解決。實際的系統會限制場地（固定光線、固定角度）、要求連續幾張都偵測到、並且讓人做最後的確認。

09

請 AI 幫你寫

你要準備
要做哪一種任務（分類、偵測、分割、姿勢）、要認哪些類別、畫面從哪裡來（電腦鏡頭、ESP32-CAM 的網址、照片）、你的環境（Python 3.13、用 uv 管理、ultralytics 的版本，用 uv pip list 查）。
AI 能幫你
寫讀取畫面、跑模型、畫框的程式；解釋結果裡每個欄位的意思；寫一個調 HSV 範圍的小工具；把結果整理成「連續幾張都有才算數」的判斷。
怎麼查證
先拿幾張已知答案的照片測（有人、沒人各幾張）；讓程式印出每一張的類別和信心度；寫法以 Ultralytics 官方文件為準。
常見陷阱
  • AI 用舊模型（yolov5、yolov8）或舊的寫法。說清楚：我用 ultralytics 8.4 版和 yolo26n.pt。
  • AI 叫你 pip install。改用 uv add。
  • OpenCV 的顏色順序是 BGR 不是 RGB，H 是 0–179 不是 0–360。AI 寫錯時顏色範圍會完全不對。
  • AI 裝了 opencv-python-headless：這個版本沒有視窗，cv2.imshow 會出錯。
