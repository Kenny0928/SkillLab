感測

光達與攝影機看前方，輪子編碼器算出走了多遠。

判斷

主控板規劃路線，遇到障礙決定停下或繞過。

執行

馬達驅動板控制左右輪的轉速。

紀錄

存下店內地圖和每一趟的行駛紀錄。

傳送

透過 Wi-Fi 接收送餐指令，回報位置與電量。

互相影響

編碼器量到輪子轉了多少，主控板再修正馬達轉速。

感測

慣性感測器（IMU）量傾斜，GPS 定位，氣壓計量高度。

判斷

飛控板依遙控指令和定位資料，決定往哪飛、飛多高。

執行

電子調速器控制四顆馬達的轉速。

紀錄

飛行紀錄存在飛控，影片存在記憶卡。

傳送

遙控指令往上送，即時影像與電量往回傳。

互相影響

IMU 量到機身傾斜，飛控板立刻調整馬達轉速，機身再回到水平。

感測

地感線圈偵測到車，攝影機拍下車牌。

判斷

辨識車牌，比對是不是月租車。

執行

柵欄機抬起柵欄，顯示幕秀出車牌。

紀錄

存下車牌、進場時間與照片。

傳送

現場控制器把紀錄送到伺服器，繳費機再用車牌查回來。

互相影響

月租名單由伺服器傳到現場，判斷才知道這台車要不要收費。

  3. 送餐機器人 03 / 05

    Wi-Fi 斷線，機器人要停下還是繼續送？

  4. 送餐機器人 04 / 05

    輪子打滑，位置算錯了，機器人怎麼發現？

  5. 送餐機器人 05 / 05

    地板反光或桌腳太細，感測器沒看到，要加裝什麼？

  1. 空拍機 01 / 05

    遙控訊號斷了，要原地降落還是自動返航？

  2. 空拍機 02 / 05

    在室內或橋下收不到 GPS，怎麼定位？

  3. 空拍機 03 / 05

    風太大，馬達出力不夠，多大的風就不該飛？

  4. 空拍機 04 / 05

    天氣冷，電池電壓掉得太快，起飛前要先做什麼？

  5. 空拍機 05 / 05

    指南針被金屬干擾，飛控怎麼知道方向錯了？

  1. 停車場 01 / 05

    網路斷了，柵欄要不要開？

  2. 停車場 02 / 05

    有人跟著前車出去，柵欄要多快放下？

  3. 停車場 03 / 05

    晚上或下雨，車牌拍不清楚，要放行還是人工確認？

  4. 停車場 04 / 05

    車牌認錯一個字，出場查不到進場紀錄，要收多少錢？

  5. 停車場 05 / 05

    柵欄放下前，怎麼確定車子已經離開？
